# Contributing to Dev Profile Generator

First off, thank you for considering contributing to the **Dev Profile Generator**! It's people like you that make open source such a great community.

We are specially focused on welcoming **first-time contributors**. If you have never made a Pull Request before, do not be afraid! We are here to help you.

## 🚀 How to Make Your First Contribution

### 1. Find an Issue
Check out our [Issues](https://github.com/diogobessaft1/dev-profile-generator/issues) tab. Look for issues with the label `good first issue` or `help wanted`. Pick one that you like!

### 2. Fork the Repository
Click the "Fork" button at the top right of this page to create a copy of this repository in your own GitHub account.

### 3. Clone Your Fork
Clone your forked repository to your local machine:
```bash
git clone https://github.com/YOUR-GITHUB-USERNAME/dev-profile-generator.git
cd dev-profile-generator
```

### 4. Create a Branch
Create a new branch for your feature or bug fix:
```bash
git checkout -b my-new-feature
```

### 5. Run the Project Locally
Install the dependencies and start the local server:
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser. You should see the application running!

### 6. Make Your Changes
Make your code changes. 

### 7. Commit and Push
Once you are happy with your changes, commit them and push to your fork:
```bash
git add .
git commit -m "Add my new feature"
git push origin my-new-feature
```

### 8. Open a Pull Request (PR)
Go back to the original repository on GitHub. You will see a green button saying "Compare & pull request". Click it, describe what you changed, and submit it!

## 💡 Code of Conduct
Please be kind and respectful to everyone. We are a community of learners and builders.

If you have any questions, feel free to ask in the issue comments!
